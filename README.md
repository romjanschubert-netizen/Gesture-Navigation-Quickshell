# ios-pill for Caelestia (Quickshell/Hyprland)
iOS-like Home-Pill for touch devices
appears in fullscreen, dissappears after 5s,
swipe up to end fullscreen.

- `ContentWindow.qml`: customized file (`modules/drawers/`)
- `ios-pill.patch`: the same change as a patch (if empty, use the QML file)
- `exitfs`: to `~/.local/bin/` copy (needs `jq`, Hyprland >= 0.55)
